<h> How to use that thing </h>

This helper script was created in order to be able to find the source-console and https links in the whole book and compare them with the English version.
This is crucial in order to keep the Greek translation align with the English one. The Asciidoctor editor can be very error prune if any symbol of ' is not
closed, or if the [source, console] is not closed. If this happens, is not easy to find the error, because it won't show the error at the exact line, but
somewhere else in the book. To search for that error, can be very tedious and can consume many hours in order to find the solution.

That's why this helper is created. To help for finding and compare the key points of the Greek translation with the English one.
